# Handling Inappropriate AI Requests

This directory contains documentation on how inappropriate or out-of-scope requests are handled in accordance with responsible AI principles.

## Documents

- **[RESPONSIBLE_AI_RESPONSE.md](RESPONSIBLE_AI_RESPONSE.md)** - English version explaining why cryptocurrency price prediction requests cannot be fulfilled
- **[RESPONSIBLE_AI_RESPONSE_JA.md](RESPONSIBLE_AI_RESPONSE_JA.md)** - Japanese version (日本語版) of the responsible AI response

## Purpose

These documents serve as examples of:
- Responsible AI practices in action
- How to handle requests that fall outside appropriate use cases
- Applying the principles taught in [Lesson 03: Using Generative AI Responsibly](../03-using-generative-ai-responsibly/README.md)

## Key Takeaways

1. **AI systems should not be used for financial predictions** that could lead to harm
2. **Educational AI repositories** have specific purposes and should not be misused
3. **Responsible AI** means recognizing when a request is inappropriate and declining it appropriately
4. **Transparency** is key - explaining why a request cannot be fulfilled helps users understand AI limitations
